## Frozen generation and sampling procedure

The normative sampling/screening implementation is the pre-authoring pinned `scripts/ai_e2_bank.py`. Use Python `random.Random(20261014)` for a 100-slot plan. Begin categories in numeric order 0 through 30; shuffle them once, then shuffle the ordered grade list (nine `slight_boost`, eight `strong_reduction`, eight `exclusion`). Visit zero-based n=0..99: class is (compound, graded, floor, conditional)[n//25], target is shuffled_categories[n%31], and only compound/conditional consume an RNG choice from that shuffled list with the target removed. Graded subtype uses shuffled_grades[n-25]. This ensures every category is a target. Compound is moderate boost of target plus moderate reduction of secondary; floor is moderate reduction of target retaining at least one; conditional is moderate boost of target limited to each item's target/secondary intersection. Plan is custodian-only and is not the reference annotation.

IDs are opaque `q_` plus the first 12 hex digits of SHA-256 of `AIREF-E2-20261014-v1:slot:N`. The author produces three wording candidates per slot in ordinal order, using only exact assigned category IDs, natural request wording, 12–45 whitespace-delimited words and no JSON, schema answer, explanation, explicit label/class tag or extraneous category. It must avoid repetitive boilerplate and clearly specify same-item scope for conditional intent. The author does not produce the study's reference answers.

The custodian considers each slot in numeric order and takes the first candidate passing all frozen text checks. Normalize text by casefolding, canonicalizing category mentions to first-occurrence placeholders C0/C1, replacing runs outside Python regex `\\w` with whitespace and collapsing spaces.
