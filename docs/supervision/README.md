## What to send each week

Keep the update to a page: evidence-backed progress, time actually spent, the main obstacle, decisions needed and next actions. Link to a specific release or commit rather than silently replacing an attachment. A report may say that a recorded run achieved a result; it may say "I reran it" only after the student actually did so and retained the log.
